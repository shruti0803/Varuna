# AI Agent Reflection

During this project, I leveraged multiple AI agents (ChatGPT, Claude Code, Copilot) to assist with building a full-stack React + Prisma dashboard for Fuel EU compliance.

## Learnings
- AI agents accelerated the creation of complex React components like `BankingTab` and `PoolingTab`.
- Learned how to implement robust fallback logic using dummy data to handle API failures.
- Gained understanding of Prisma queries and handling Postgres schema without modifications.

## Efficiency Gains
- Components with full state management, memoization, and API integration were generated in minutes instead of hours.
- Agents helped refactor and clean repetitive Tailwind and JSX code efficiently.
- Prompt-based iteration allowed refining logic like poolSum calculations and button enable/disable rules quickly.

## Improvements Next Time
- Predefine all fallback dummy data structures for faster integration.
- Add unit tests during AI-assisted generation to validate functionality automatically.
- Integrate agent-assisted backend + frontend consistency checks to prevent runtime undefined errors.
